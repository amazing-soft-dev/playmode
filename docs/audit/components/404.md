# 404 Page

Served for `/404` and any unknown path with **HTTP 404** (no soft redirect). Status **C**. Screenshot: `.research/audit/screenshots/404/1440-0.jpg`.

## Layout
- Header (transparent variant) + 404 Section + footer.
- 404 Section: **100vh** (900 at 1440×900), black, content centred both axes.
- 404 Container: column, `gap: 40px; padding: 0 20px; align-items: center`.
  - Content (column `gap: 20px`): Title group (column `gap: 30px`):
    - "404": Geist Mono **100px / weight 100 / line-height 1.2 / −1px** (80px ≤1279), #fff.
    - H2: Host Grotesk 40/500/1.2/−1px uppercase ("Something's not right.").
  - Body: Geist Mono 16/300/1.5, centred.
  - Primary Button "Back to homepage" (244×48) → `/`.
- No background video/image on this section.

## Motion
- Elements reveal on load (fade + 20px rise, 600–800ms). Button hover as `button-cta.md`.
